Atividade tema escolhido:Sistema para restaurante.

Requisitos funcionais:

O sistema deve permitir o cadastro, edição e exclusão de usuários.
O sistema deve permitir cadastrar, editar, listar e remover itens do cardápio.
O sistema deve permitir a criação, alteração e cancelamento de pedidos.
o sistema deve permitir o controle de status das mesas mesas.
O sistema deve enviar automáticamente os pedidos confirmados para a cozinha.
O sistema deve permitir o acompanhamento do pedido em tempo real.
O sistema deve permitir o fechamento da conta por mesa ou pedido.
O sistema deve permitir o registro pagamentos em diferentes formas (pix, pagamento, cartões).
